# Abasto

Sistema ERP multi-tenant para supermercados mayoristas.

## Estructura inicial

- `backend/`: API NestJS + TypeScript.
- `frontend/`: aplicación React + TypeScript.
- `infra/docker/`: infraestructura local, incluyendo PostgreSQL.
- `docs/`: decisiones y diseño del sistema.

El código funcional, las migraciones y el seed se incorporarán después de validar el modelo de datos base.
